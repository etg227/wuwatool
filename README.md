# WuWa Echo Marginal Scorer / 鸣潮单角色声骸边际评分器

一个纯前端、可直接部署到 GitHub Pages 的《鸣潮》单角色声骸理论工具。它不使用固定 CV 作为最终评价，而是根据角色当前面板、战斗态自拐、主要伤害类型和共鸣链相关修正，重新计算每条声骸词条的 **实际边际收益**。

## 当前功能

- **单角色模式**：不再包含配队、队友 Buff 或输出窗口。
- **角色卡片选择**：角色名称和头像来自库街区《鸣潮》WIKI 角色目录快照。
- **共鸣链 0–6 记录**：玩家可选择当前共鸣链。
- **ATK / HP / DEF 倍率角色**：可指定角色主要倍率属性，避免所有角色被错误按 ATK 计算。
- **静态面板 + 战斗态修正**：静态面板填写实际装备后的数值；未显示在静态面板里的自拐 / 共鸣链临时攻击、双暴、增伤和 Amplify 可单独录入。
- **5 只声骸独立评分**：每个装备位可填写 COST、2 条主属性和 5 条副属性，并分别计算边际评分。
- **候选声骸替换**：指定替换 1–5 号声骸后，计算整套理论提升。
- **副词条逐条收益**：候选声骸的每条副词条都会单独显示对当前角色的边际贡献。
- **稀释边界**：比较当前配置下 CR、CD、主要倍率属性%、类型伤等标准词条的即时收益。
- **ER 不强行换算伤害**：共鸣效率属于阈值属性，当前模型不会伪造固定 DPS 权重。

## 边际评分定义

每只声骸的评分不是固定 CV，而是先在当前角色配置下求标准词条的实际边际收益。

以当前最值钱的“平均档有效词条”为 1 个等效词条：

```text
等效词条_i = ln(1 + 第 i 条实际边际收益) / ln(1 + 当前最优平均档词条收益)

单只声骸边际评分 = Σ(5 条副词条等效词条) / 5 × 100
```

因此：

- `100` 代表 5 条副词条都大致达到“当前角色最优平均档词条”的价值。
- 同样一条 16.8% 暴伤，在低爆伤角色上可能价值较高，在高自拐爆伤角色上会明显掉分。
- 同一只声骸换到不同倍率属性、不同双暴、不同伤害构成的角色上，评分可以不同。

## 替换计算

玩家填写的“当前总值”应包含当前 5 只已装备声骸。

替换第 `n` 只声骸时：

```text
候选面板 = 当前面板 - 第 n 只旧声骸属性 + 候选声骸属性

替换收益 = CandidateFactor / CurrentFactor - 1
```

这样不需要重新手工计算整套面板。

## 共鸣链口径

当前版本允许选择 0–6 链，但不会假装已经把每个角色所有共鸣链文本机制完整自动建模。

处理规则：

1. **已经显示在静态面板里的永久属性**：直接体现在“当前总值”中，不重复添加。
2. **战斗中才出现的攻击%、CR、CD、Damage Bonus、Amplify**：填入“战斗态自拐 / 共鸣链修正”。这些修正会真实改变声骸边际收益。
3. **只给所有伤害同一个固定独立倍率的链效果**：如果它对新旧声骸完全相同，会在 Candidate / Current 比值中相消，因此不会改变声骸边际排序。
4. **改变技能倍率、伤害构成、特殊转化或异常伤害公式的共鸣链**：需要角色专属机制模型，当前阶段不自动猜测。

后续会把角色机制库和共鸣链预设逐步补齐，再让“角色 + 共鸣链”自动带出这些修正。

## 核心公式

```text
期望暴击乘区 = 1 + min(CR, 100%) × (CD - 100%)

伤害加成乘区 = 1 + 全局/属性伤害加成 + 对应攻击类型伤害加成
Amplify 乘区 = 1 + 全局 Amplify + 对应攻击类型 Amplify

Factor = 主要倍率属性 × 伤害加成乘区 × Amplify 乘区 × 期望暴击乘区
```

若主要伤害类型占比为 `q`：

```text
总 Factor = q × 主要类型 Factor + (1 - q) × 其他伤害 Factor
```
