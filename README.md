# WuWa Echo Marginal Scorer / 鸣潮单角色声骸边际评分器

一个纯前端、可直接部署到 GitHub Pages 的《鸣潮》单角色声骸理论工具。它不使用固定 CV 作为最终评价，而是根据角色当前面板、共鸣链、武器/合鸣套装和角色伤害构成，重新计算声骸副词条的实际边际收益。

## 当前功能

- **单角色模式**：不包含配队、队友 Buff 或输出窗口。
- **角色卡片选择**：角色名称和头像来自库街区《鸣潮》WIKI 角色目录快照；角色切换时会清空上一角色的面板、声骸和候选声骸。
- **角色机制库**：陆·赫斯及以前优先复用 WuwaEchoTool 已整理的数据，后续角色由本项目继续维护；前瞻/未正式校验角色会单独标记，不冒充正式服最终数据。
- **共鸣链 0–6**：已建模角色会自动读取对应链数带来的战斗态修正和伤害构成变化。
- **ATK / HP / DEF 倍率角色**：角色可按其主要倍率属性进行边际收益计算。
- **当前静态面板**：玩家只填写游戏角色详情页当前面板；`baseline-sync.js` 会把初次完整录入的“非声骸底座”锁定，之后修改声骸时让模拟面板随之变化。
- **完整合鸣套装数据库**：主套装会列出当前数据库中的全部套装。选择主套后再选择合法件数（5件 / 3件 / 特殊1件）；只有主套为3件时才能选择2件副套，5件时副套装锁定。
- **武器被动**：已校验的专武效果可自动计入。
- **5只声骸独立评分**：每个装备位可填写 COST、主词条与5条副词条，并分别计算边际评分与 SSS–D 评级。
- **固定档位下拉**：副词条数值只允许选择游戏内实际档位；4-COST 支持暴击、暴伤、攻/生/防和治疗效果主词条。
- **候选声骸替换**：指定替换1–5号声骸后，计算整套理论提升。
- **候选逐条贡献**：候选声骸每条副词条都会单独显示对当前角色的边际贡献。
- **可实现的提升建议**：推荐器不会把“凭空再加一条词条”当成养成建议，而是检查5只现有声骸的真实提档空间或可替换弱词条；全套已满档的词条会被判定为饱和。
- **本机配置保存**：角色、共鸣链、面板、主/副套装结构与5只声骸都可保存在浏览器本地，方便反复比较。
- **ER 不强行换算伤害**：共鸣效率属于阈值属性，当前模型不会伪造固定 DPS 权重。

## 合鸣套装逻辑

主套装选择器始终列出数据库中的全部可用套装，然后根据该套装实际存在的效果开放合法件数：

```text
5件主套：
  主套 2件效果 + 主套 5件效果
  2件副套锁定，不参与计算

3件主套：
  主套 3件效果 + 副套 2件效果
  只有此时可选择2件副套

特殊1件：
  只应用该套装的1件效果
```

触发型效果按数据中定义的已触发/满层口径处理；如存在明确阈值（例如 ER ≥ 250%），会先检查条件再加入计算。

## 边际评分定义

每只声骸的评分不是固定 CV，而是先在当前角色配置下求标准词条的实际边际收益。

以当前最值钱的“平均档有效词条”为1个等效词条：

```text
等效词条_i = ln(1 + 第 i 条实际边际收益)
            / ln(1 + 当前最优平均档词条收益)

单只声骸边际评分 = Σ(5 条副词条等效词条) / 5 × 100
```

因此：

- `100` 代表5条副词条都大致达到“当前角色最优平均档词条”的价值。
- 同样一条暴伤，在不同暴击率、不同自拐与不同套装下价值会变化。
- 同一只声骸换到不同倍率属性、不同伤害构成或不同共鸣链角色上，评分可以不同。
- 副词条允许按游戏中的实际行顺序录入；中间留空不会再改变评分对象。

## 替换计算

玩家填写的当前面板应对应当前已装备的5只声骸。录入完整后，工具会锁定非声骸底座。

替换第 `n` 只声骸时：

```text
候选状态 = 非声骸底座 + 其余4只当前声骸 + 候选声骸
替换收益 = CandidateFactor / CurrentFactor - 1
```

因此不需要玩家手动重算换装后的整套面板。

## 核心公式

```text
期望暴击乘区 = 1 + min(CR, 100%) × (CD - 100%)

伤害加成乘区
= 1 + 全局伤害加成 + 属性伤害加成 + 对应攻击类型伤害加成

Amplify 乘区
= 1 + 全局 Amplify

Factor
= 主要倍率属性 × 伤害加成乘区 × Amplify 乘区 × 期望暴击乘区
```

角色伤害由其机制库中的普攻 / 重击 / 共鸣技能 / 共鸣解放 / 其他伤害权重进行加权，而不是要求玩家手工填写“主要伤害类型占比”。

## 数据

- 角色目录：库街区《鸣潮》WIKI。
- 旧角色伤害构成与评分基础：WuwaEchoTool（作者已公开说明项目数据可取用）。
- 新角色与新套装：继续结合库街区与仍在更新的社区数据源进行维护和交叉校验。
- 声骸固定副词条档位：按游戏实际档位维护。
- `wuwa/data/sonata-effects.json`：当前合鸣套装效果数据库。
- `wuwa/data/character-mechanics.json` / `character-mechanics-extra.json`：角色机制与补充模型。

详细来源与公式说明见 [`REFERENCES.md`](./REFERENCES.md)。
